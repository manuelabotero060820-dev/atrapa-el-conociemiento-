Atrapa el conocimiento
1. Descripción del proyecto

Atrapa el conocimiento es una propuesta de videojuego educativo diseñada para promover el aprendizaje de forma interactiva y entretenida.

2. Objetivo general

Organizar y documentar las actividades necesarias para el desarrollo de un producto digital, utilizando Trello para la planeación y GitHub para la gestión técnica y el control de versiones.

3. Herramientas utilizadas

Trello: permite organizar las tareas, asignar responsables, establecer fechas de entrega y hacer seguimiento al avance del proyecto.

GitHub: permite almacenar la documentación, registrar cambios y mantener un historial de los avances del proyecto.

4. Organización del trabajo

Las actividades se organizarán en etapas de planeación, desarrollo, revisión y finalización. Cada tarea deberá tener un responsable y un estado de avance.

5. Seguimiento y control

Se utilizarán las tarjetas de Trello para hacer seguimiento a las actividades y los commits de GitHub para registrar los cambios realizados en los archivos del proyecto.

6. Evidencias del proyecto

En este repositorio se almacenará la documentación y las evidencias técnicas que se generen durante el desarrollo de la actividad académica del SENA.
